02 // GHL Automation

Two orders. Two follow-up paths.

Actual builder captures from the October 2026 workflows. The breakdown follows the configured trigger and action order.

Workflow 01 // Postage Only

Positively Geared Postage Only

The standard book order gets its own purchase tag, customer confirmation, and internal handoff.

  1. Match the book order

    An Order Submitted trigger filters for the Positively Geared product, Form order source, and a specific product price.

  2. Wait 15 seconds

    A short buffer runs before the postage-only confirmation steps.

  3. Tag the purchase

    Applies the tag “$12 - positively geared only 2026” to identify the standard order.

  4. Send the order confirmation

    The customer receives the workflow's Order Confirmation email.

  5. Notify the team

    Two Purchased internal notifications follow: one to the info inbox and one to Lloyd.

The delay provides a short window before the standard-order messages. The upgrade workflow explicitly removes a buyer from this workflow when its trigger matches.
Workflow 02 // Postage with Bump

Positively Geared Postage with Bump

The Set for Life upgrade takes a separate route, coordinating with the standard order flow before sending its own confirmation.

  1. Match the upgrade order

    An Order Submitted trigger filters for Set for Life, Form order source, and its specific product price.

  2. Exit the postage-only workflow

    The first action removes the contact from Positively Geared Postage Only.

  3. Tag the upgraded purchase

    Applies “$19 - positively geared + set for life 2026” to distinguish the combined order.

  4. Send the upgrade confirmation

    This path sends its own Order Confirmation email.

  5. Notify the team

    Purchased notifications go to the info inbox and Lloyd, as in the standard-order path.

The removal action is intended to keep the two confirmation paths distinct. This walkthrough documents the setup, not measured delivery, sales, or conversion results.
